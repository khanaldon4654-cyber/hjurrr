FRIENDSHIP WEBPAGE — AMRIT & SWASTIKA

Files:
- index.html: complete responsive friendship website.

How to preview:
1. Extract the ZIP.
2. Double-click index.html to open it in your browser.

How to publish:
1. Create a public GitHub repository.
2. Upload index.html.
3. In repository Settings, open Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Once GitHub gives you a public website URL, create a QR code using that URL.
6. You can add the QR image to the website or print it and paste it into the blank QR box on the Friendship License.
